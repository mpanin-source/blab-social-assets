# Built Like A Brand — social assets

Public host for scheduled social media assets. Buffer's API fetches media by URL and has no
upload endpoint, so published post assets live here and are served via raw.githubusercontent.com.

Contains only finished, already-public marketing material for @builtlikeabrand. Concept-brand
imagery (VELA · SABLE · VOLT · KURB) is labelled as concept work wherever it is posted.
